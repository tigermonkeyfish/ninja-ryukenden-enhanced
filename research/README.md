# Research material

- `comparison-runs/`: the button-input runs behind the Original vs Enhanced
  comparison videos, one per enhanced stage entry
  ([docs/COMPARISON-VIDEOS.md](../docs/COMPARISON-VIDEOS.md)).
- `tools/`: the probes behind the background-fidelity, timing, slowdown and
  load-time work, kept as reference implementations
  ([index](tools/README.md)). They are not a supported build path.

For current work use `scripts/project.py`, `src/` and
[docs/HANDOFF.md](../docs/HANDOFF.md). For another game use
[docs/pc-engine/](../docs/pc-engine/README.md); those guides say which
findings transfer and which need a fresh audit.
