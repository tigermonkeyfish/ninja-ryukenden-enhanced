# The in-game menu (scripts/menu_text.py builds menu-text.inc from this).
#
# The popup window, 25 columns x 11 rows between the bars, drawn over the
# playfield at screen columns 3-27, BAT rows 7-17. '#' runs are the value
# fields: STAGE, then one per option row (the @ lines below, in order). The
# '!' run is the reset row's field (the ! line below): selectable after the
# option rows; I or II there sets every option to its default (the first
# value of each @ line). The '?' run is the save status field (the ? line
# below; not selectable): the window's top line, a blank row from the
# options; another blank row parts the options from the controls line at
# the bottom.
| ??????????????????????? |
|                         |
| STAGE: #####            |
| SMOOTH PARALLAX: ###    |
| NO DAMAGE: ###          |
| NES FIREWHEEL: ###      |
| PALETTE: ##########     |
| LANGUAGE: ########      |
| RESET OPTIONS: !!!!!!!  |
|                         |
| RUN: OK  SELECT: CANCEL |
#
# The band under the HUD (BAT row 31) while the menu is open, centred in 32
# columns. {credit} is GITHUB.COM/TIGERMONKEYFISH when the line fits, else
# TIGERMONKEYFISH.
= V{version} {credit}
#
# Option values: the draft-byte bits the field owns, then value=TEXT in
# Left/Right order ('_' is a space). Draft bits 0-5 are $2100's options on
# Run (0 original background, 1 No Damage, 2 NES Firewheel, 3-5 palette
# mode: $00 Original, $08 NES-A, $28 NES-B, $10 GB DMG, $18 APOCALYPSE
# (named HELL in the source), $38 SMS; $20 and $30 unassigned; see
# src/palette/main.asm; the menu sets $2100 bit 7 with SMS); bits 6-7 the
# language ($3227: 0 Japanese, 1 English, 2 Chinese). The first value of
# each line is the option's default, the one the reset row sets: the power-on
# settings without saved ones (src/bram: $2100 = 0, $3227 = 1 English).
@ $01 $00=ON $01=OFF
@ $02 $00=OFF $02=ON
@ $04 $00=OFF $04=ON
@ $38 $00=ORIGINAL $18=APOCALYPSE $08=NES-A $28=NES-B $38=SMS $10=GB_DMG
@ $c0 $40=ENGLISH $00=JAPANESE $80=CHINESE
#
# The reset row's field text ('_' is a space); it blinks while the row is
# selected.
! PRESS_I
#
# The save status (src/bram/main.asm, $2105), in the order of its ST_
# values: no backup RAM; settings loaded or saved; backup RAM ready, nothing
# saved yet; backup RAM full; then the errors: 1 unformatted and not blank,
# 2 directory damaged, 3 an entry of our name with another size, 4 the save
# did not read back, 5 our entry's contents do not check out (defaults used;
# the next Run rewrites it). Nothing is written in cases FULL and ERROR 1-3.
# OK is a Run's save (or the settings already saved); LOADED, added last,
# the settings read at power-on or reset.
# Plain statements, not prompts (scripts/bram_image.py STATUS_TEXT).
? NO_BACKUP_MEMORY SETTINGS_SAVED BACKUP_MEMORY_FOUND BACKUP_MEMORY_FULL BACKUP_MEMORY_ERROR_1 BACKUP_MEMORY_ERROR_2 BACKUP_MEMORY_ERROR_3 BACKUP_MEMORY_ERROR_4 BACKUP_MEMORY_ERROR_5 SETTINGS_LOADED
